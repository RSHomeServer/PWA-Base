# @platform/math

Small numeric and sample-statistics helpers. No React dependency.

## Public import

```typescript
import { clamp, lerp, mean, stdevSample } from "@songara/pwa-base/math";
// or workspace: import { clamp } from "@platform/math";
```

## API

- Numeric: `clamp`, `lerp`, `inverseLerp`, `linspace`
- Stats: `sum`, `mean`, `varianceSample`, `stdevSample`

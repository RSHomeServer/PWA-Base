# `@platform/preview-howler`

**Preview** thin SFX façade around [Howler.js](https://howlerjs.com/).

> **Unstable.** Prefer `@songara/pwa-base/preview/howler` from sibling apps.

**Important:** Does **not** replace Stable `AudioEngineProvider`
(`@songara/pwa-base/audio`). Use Howler for simple multi-format one-shots.

```bash
pnpm add howler
pnpm add -D @types/howler
```

## Intended Stable home

Optional SFX helpers beside `/audio`, then deprecate `/preview/howler`.

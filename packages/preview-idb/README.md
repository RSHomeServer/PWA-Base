# `@platform/preview-idb`

**Preview** thin integration around [idb](https://github.com/jakearchibald/idb).

> **Unstable.** Prefer `@songara/pwa-base/preview/idb` from sibling apps.

Prefer `@songara/pwa-base/preview/dexie` when you want schema-version factories.
Use this for low-level IndexedDB promise access with Songara naming.

```bash
pnpm add idb
```

## Intended Stable home

`@songara/pwa-base/storage` (or offline) kit — not Content Pack storage.

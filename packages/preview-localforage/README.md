# `@platform/preview-localforage`

**Preview** thin integration around [localForage](https://localforage.github.io/localForage/).

> **Unstable.** Prefer `@songara/pwa-base/preview/localforage` from sibling apps.

```bash
pnpm add localforage
```

## Intended Stable home

`@songara/pwa-base/storage` — not Content Pack storage.

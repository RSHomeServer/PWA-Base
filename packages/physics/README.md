# @platform/physics

Renderer-agnostic fixed-timestep simulation engine (World/System scheduling, particles, forces, constraints, fields, oscillators). No DOM/Canvas/React.

## Public import

```typescript
import { World, ParticleBuffer } from "@songara/pwa-base/physics";
// or workspace: import { World } from "@platform/physics";
```

See `src/index.ts` for the full export surface. Depends on `@platform/math`.

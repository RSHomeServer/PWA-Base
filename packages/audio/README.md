# @platform/audio

Product-neutral Web Audio building blocks for Songara PWAs:

- **Master graph** — lazy `AudioContext` with gain, safety compressor, and analyser
- **React integration** — `AudioEngineProvider` + `useAudioEngine` for shared lab/app graphs
- **Analysis** — RMS, dB conversion, K-weighting filter, phase correlation, FFT band energies

No exhibit routes, stem packs, or demo song arrangements — those stay in consuming apps.

Published from the monorepo as `@songara/pwa-base/audio`.

# @platform/markdown

GFM Markdown React renderer with syntax highlighting.

## Public import

```typescript
import { Markdown } from "@songara/pwa-base/markdown";
import "@songara/pwa-base/markdown/styles.css";
// or workspace: import { Markdown } from "@platform/markdown";
```

## API

- `Markdown` — React component (`MarkdownProps`, `MarkdownVariant`).
- Styles: `@songara/pwa-base/markdown/styles.css` (or `@platform/markdown/styles.css`).

React is a peer dependency.

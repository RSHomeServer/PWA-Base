# @platform/controls

Parameter control panel for interactive demos and analysis UIs.

## Public import

```typescript
import { ParameterPanel } from "@songara/pwa-base/controls";
// or workspace: import { ParameterPanel } from "@platform/controls";
```

## API

- `ParameterPanel` — React panel driven by `ParamDef[]` (number, boolean, select, text).
- Types: `ParamDef`, `ParamValue`, `ParamValues`, and per-kind defs.

Depends on `@platform/ui` and React (peer).

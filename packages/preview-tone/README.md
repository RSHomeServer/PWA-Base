# `@platform/preview-tone`

**Preview** thin integration around [Tone.js](https://tonejs.github.io/).

> **Unstable.** Prefer `@songara/pwa-base/preview/tone` from sibling apps.

**Important:** This does **not** replace Stable `@songara/pwa-base/audio`
(`AudioEngineProvider` / master graph). Use Tone for synthesis & Transport labs.

```bash
pnpm add tone
```

## Intended Stable home

Optional creative-audio surface beside `/audio`, or remain Preview until product proof.
